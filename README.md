# 航电密钥轮换演练 · 双模块共同确认复核

浏览器端复核工具：针对**两枚独立安全模块**，在 Web Worker 中**穷尽**所有
保持控制端顺序的消息投递、三窗口断电与落盘重放恢复交织，判定它们是否会在任何
执行方式下**共同确认一份由不同纪元密钥签出的发布令**。发现违约时给出
**动作数最短**、同长度按模块/指令标识稳定排序的完整交织及每步双模块状态；
安全时给出已覆盖状态摘要。

## 协议与威胁模型

- 控制端按固定顺序下发至多 **16** 条指令（按发起顺序排列）：
  - `prepare`（准备密钥）、`activate`（激活换纪元）、`issue`（签发发布令）、`recover`（断电恢复）。
- 每条处理可在三个窗口**任意断电**：
  - `before` 持久写入前（效果不存在）；
  - `preack` 持久写入后、确认发出前（落盘保留、无后续消息）；
  - `after` 确认发出后。
- **消息延迟不乱序**：通道按 `发送方→接收方` 保持 FIFO；
  **确认重发**：签署请求/确认在丢失或未可靠完成时，发送方可显式重发**一份**副本（有界一次）。
- **恢复只重放已落盘记录**：断电丢失运行态与在途消息，上电后持久日志重放出同样规范状态。
- **重复/迟到确认幂等**：已确认的发布令记录不被覆盖；
  **签发成功**仅当两模块均持久激活同一纪元、且都以该纪元密钥确认同一发布令。
- **违约判据**：同一发布令标识同时出现在两模块已确认集合，且记录的签发密钥指纹不同。

模块的持久规范状态为三段：

```
{ 持久纪元 epoch, 准备密钥 pending, 已确认发布集合 confirmed(发布令 → 签发密钥指纹) }
```

## 穷尽与合并

- BFS 保证证人**动作数最短**；每个状态的后继按
  `(动作类型, 模块标识, 指令序号, 发布令标识, 消息种类, 来源, 断电窗口)` 稳定排序，
  故同长度取字典序最小的完整交织。
- 穷尽合并键 = 双模块持久三段 + 宕机标志 + 各 FIFO 在途环境 + 重发令牌多集。
  仅按三段持久状态合并前缀并不安全（相同持久状态下在途消息不同，后续落地结果也不同）。
- 不同发布令的请求/确认彼此独立、处理可交换，模块间通道按**消息签名多集**合并；
  控制端通道严格保序。该交换性由 `scripts/fuzz-multiset.js` 差分测试验证
  （严格 FIFO 键 vs 多集键，数千随机场景判定与最短证人长度一致）。
- 极度对抗性输入（如 16 条全部为相互独立的发布令签发）会触及搜索上限，
  此时页面明确显示「搜索被截断」而非给出不安全结论；实际轮换序列（少量发布令）为毫秒级。

## 输入校验（一次性指出并清除旧结论）

模块标识重复、未知密钥指纹、非法初态（如纪元 0 不用旧密钥）、无效指令目标、
恢复前无故障、发布令/指纹格式错误、指令超限等都会聚合列出，并清空既有结论。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器（含 /healthz）
npm test           # 核心状态测试（node --test）
npm run build      # 静态构建检查
node scripts/smoke.mjs   # 对运行中的服务做页面/健康/Worker 冒烟
node scripts/fuzz-multiset.js [seed] [n]   # 交换性差分 fuzz
```

## Docker Compose

宿主机端口可通过 `HOST_PORT` 配置（默认 `8080`）：

```bash
docker compose up --build -d                 # 打开 http://localhost:8080
HOST_PORT=9000 docker compose up --build -d  # 自定义端口
curl http://localhost:8080/healthz
```

一次性 verify（核心状态测试 + 静态构建检查 + 页面与健康地址 HTTP 冒烟，
**完成后以退出码结束**：0 成功、非 0 失败）：

```bash
docker compose --profile verify run --rm verify ; echo "exit=$?"
```

## 目录

- `src/engine/protocol.js` — 纯函数协议与穷尽搜索（Worker 与 Node 测试共用，无 DOM 依赖）。
- `src/workers/review.worker.js` — 后台 Worker，承载穷尽计算与进度汇报。
- `src/main.js` / `src/styles.css` / `index.html` — 录入、校验与证人/摘要展示。
- `test/protocol.test.js` — 核心状态测试。
- `scripts/smoke.mjs` — HTTP 冒烟；`scripts/fuzz-multiset.js` — 交换性差分验证。
- `Dockerfile`（`web` / `verify` 多目标）、`compose.yaml`、`nginx.conf`。
